Five examples:

Table geometry. A two-column table with one body cell removed. The colspec still says two columns while the row has one.
Footnote pair. Hello[^1] with its definition deleted, leaving a NoteReference whose id resolves to nothing.
Anchor link. A Link to #sec-intro after the Header carrying that id is removed.
Custom node slots. A callout where the title slot key is deleted versus emptied. Removing the key breaks the handler; an empty Inlines[] is fine.
Whitespace nodes. a b c with a Str removed, producing doubled or trailing Space nodes the parser would never emit.
