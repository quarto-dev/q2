# bslib component JavaScript

`components.js` (cards: full screen; sidebars: collapse) and
`web-components.js` (`<bslib-tooltip>` and friends; loaded as
`type="module"`), byte-identical copies from quarto-cli, which vendors them from
the R package bslib.

- quarto-cli tag: `v1.11.6`
- source: `src/resources/formats/html/bslib/components/dist/{components.js,web-components.js}`

Shipped with dashboard pages only. See `resources/scss/bslib/README.md`.
