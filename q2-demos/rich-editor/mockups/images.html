Click an image to select it, or drag it to move it: into a line of text, or between lines. Paste or drop an image file into the text, or type ![a picture](images/sales.svg). With an image selected: ⌫ removes it, ↵ starts a paragraph after it, arrows move off it, ⌘Z undoes. No image file to hand? and paste it. The choices on the left change how the document behaves; the address keeps them.
