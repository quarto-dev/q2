# 07-asides — Asides

Peripheral commentary shown small and muted at the bottom of a slide.

## What this demonstrates

- **Asides.** An `.aside` div holds secondary content, styled small and muted
  at the bottom of the slide.

## How to run

```bash
cargo run --bin q2 -- render examples/presentations/07-asides
```

## What to look for

- The aside renders as `<aside class="aside">`, positioned at the bottom of
  the slide in a smaller, lighter font.
